## Install and configure DCHP 

## Objective
Install and configure DHCP.

----
## Environment

Server Name - DC01
Operating System - Windows Server 2022 Evaluation
Domain - project.local

----

## Steps
1. Open DHCP Server
2. Click add Roles
3. Install DHCP Server and Complete DHCP configuration
4. Create a Scope:
   name - Office Network
   range 192.168.1.100 to 162.168.1.150
   Subnet- 255.255.255.0
   DNS-192.168.1.10
5. Active the scope

----
## Result

Configured DHCP 

The service installed:
DHCP

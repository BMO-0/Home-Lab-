# Making Organizational Units

## Objective 
Making active directory objects/Organizational Units

----
## Environment

Server Name - DC01
Operating System - Windows Server 2022 Evaluation
Domain - project.local

## Steps 

1.Click tools on the server manager.
2.Click Active Directory User and Computer .
3.On project.local create Created the following Security groups OUs: IT, HR, Finance, Sales, Computers, Servers, Project
  
----

## Result

Security groups have been formed

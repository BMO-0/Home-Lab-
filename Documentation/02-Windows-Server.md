# Setting up Windows Server 

## Objective

Setting up the server by configuring the network 
-------
## Environment
Server Name:
DC01

Operating System:
Windows Server 2022 Evaluation



## Steps 
1. Open control panel and navigate to Network Connections
2. Right click Ethernet, click  Properties -> IPV4 -> Configure
3. Enter: IP Address - 192.168.10.10
Subnet Mask - 255.255.255.0
Gateway  -(blank)
DNS - 192.168.1.10
4. Apply changes and then restart

-------

## Result
Gave the server a static IP

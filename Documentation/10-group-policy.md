# Group Policy

## Objective 

Use Group Policy Objects (GPO) to manage and configure settings for domain users and computers

----

## Environment
Computer Name: LabClient1
Operating System: Windows 11
Domain: project.local

----

## Policies made
1.  Control Panel restrictions
2.  Command Prompt restrictions
3.  Password policies
4.  Desktop settings

## Updating Group Policy 
After configuring policies use:
gpupdate /force and gpresult /r to update group policies.

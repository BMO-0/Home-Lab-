# VirtualBox  Virtual Machine (VM) Setup for the client

## Objective
Set up the VM to install Windows 11

## Environment

VM Name - LabClient01

Operating System -  Windows 11
Base Memory: 4096 MB
CPU: 2
Disk: 25 GB Dynamic 


## Steps
1.Click new in Oracle VirtualBox Manager 
2. Enter these details:
  Name- LabClient01
  OS ISO-Windows 11 ISO Image 
  Base Memory: 4096 MB
  Disk: 25 GB Dynamic 
3.Click  finish
4. Install Windows 
5.When installation finishes rename the computer -LabClinet1

## Result

A VM is made with Windows 11 is installed
